# Installation

## Running the Frontend

Open the frontend folder in VScode. Download VScode's live server extension. Open the `index.html` file. Right click and select **Open with Live Server**.

## Running the backend

Open a terminal. Change directory to the backend folder. Run this command if you're on windows:

`mvnw.cmd spring-boot:run`

or this for mac or linux:

`./mvnw spring-boot:run`
